# Responsive UI support

Blackbird v1 is a desktop-first rTorrent console. The interface is supported at
viewport widths of **900px and wider**.

At smaller desktop widths the sidebar changes to an accessible icon rail and the
table removes the Tracker, Added, and Ratio columns in that order. Settings,
Details, Stats, and the Add Torrent dialog continue to fit within the viewport
without page-level horizontal scrolling.

Mobile layouts below 900px are intentionally unsupported in v1. Use a desktop
or laptop-sized window for the full console experience.
